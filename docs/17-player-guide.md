# Grim Hollow — руководство игрока

## Установка клиента

**Windows x64:** распакуйте архив целиком и запустите `GrimHollow.exe`. Требуется Windows 10/11. Клиент не подписан цифровым сертификатом и не обновляется автоматически. Новую версию скачивайте из Releases того же репозитория. Сохранения находятся на сервере, а не в папке клиента.

**Linux x64:** распакуйте `.tar.gz` и запустите `./grim-hollow`. Сборка рассчитана на Debian 12/совместимую glibc-систему с GTK2 и графической сессией. Установите системные зависимости GTK2, например `sudo apt install libgtk2.0-0 libgdk-pixbuf-2.0-0 libpango-1.0-0 libcairo2 libx11-6`. Это не AppImage и не универсальный статический бинарник. Linux 0.3 поддерживает только локальный HTTP; для удалённого HTTPS-сервера используйте Windows-клиент.

Архив клиента **не содержит сервер**. Его адрес предоставляет организатор игры. В поле «Сервер» введите `https://ваш-домен` без `/api/v1` и без завершающего слеша. Для локального сервера из исходников — `http://127.0.0.1:8080`. Windows использует `/ws` на том же HTTPS-домене. Пароль и токен не записываются на диск.

Проверка загрузки: SHA256SUMS.txt рядом с архивами содержит хэши архивов; внутри каждого архива — хэши его файлов. Windows: `Get-FileHash .\имя.zip -Algorithm SHA256`; Linux: `sha256sum -c SHA256SUMS.txt`. Хэши обнаруживают повреждение, но не заменяют цифровую подпись.

## Начало игры

Создайте аккаунт (пароль минимум 12 символов), затем героя: Страж, Арканист, Следопыт или Хранитель. Во вкладке «Вещи» наденьте кольцо. «Поход» → область → «Подготовить / присоединиться» → «Начать». Друзья вводят код группы **до** начала; группа до четырёх игроков.

Щёлкните карту или нажмите Esc для управления. WASD/стрелки — шаг; Space — атака; 1 — щитовой удар, 2 — защита, 3 — зелье; 4–7 — заклинания. У золотого выхода E ведёт на следующий этаж, X возвращает с добычей. R помогает соседнему павшему союзнику. T открывает городские службы вне похода. F1 — подробный справочник.

Цель кампании: победить босса третьего этажа каждой из трёх областей и эвакуироваться. Каждый возвращённый огонь открывает следующую область. После третьего кампания завершена; дальнейшие походы и развитие остаются доступны.

В городе доступны кузница, разбор, рынок, друзья, гильдии, таланты и история операций. Добыча сохраняется при эвакуации; при поражении остаётся четверть опыта. Постоянная экипировка не пропадает.

Если герой не двигается: убедитесь, что лобби запущено, закройте поле ввода клавишей Esc, дождитесь готовности действия. При разрыве соединения клиент пытается переподключиться; после нового входа выберите прежнего героя. При несовместимости версии запросите у владельца сервера актуальный клиент.
