# Grim Hollow — руководство игрока

## Установка клиента

**Windows x64:** распакуйте архив целиком и запустите `GrimHollow.exe`. Требуется Windows 10/11. Клиент не подписан цифровым сертификатом. Он проверяет новые версии в Releases при запуске и по кнопке «Проверить обновления» во вкладке «Аккаунт». Скачанный архив сверяется с SHA-256 из релиза, после установки клиент перезапускается. Папка игры должна быть доступна для записи (не Program Files); иначе скачайте архив вручную. Отключить проверку: запуск с параметром `--no-update-check`. Сохранения находятся на сервере, а не в папке клиента.

**Linux x64:** распакуйте `.tar.gz` и запустите `./grim-hollow`. Сборка рассчитана на Debian 12/совместимую glibc-систему с GTK2 и графической сессией. Установите системные зависимости GTK2, например `sudo apt install libgtk2.0-0 libgdk-pixbuf-2.0-0 libpango-1.0-0 libcairo2 libx11-6`. Это не AppImage и не универсальный статический бинарник. Linux-клиент пока поддерживает только локальный HTTP; для удалённого HTTPS-сервера используйте Windows-клиент.

Архив клиента **не содержит сервер**. Его адрес предоставляет организатор игры. В поле «Сервер» введите `https://ваш-домен` без `/api/v1` и без завершающего слеша. Для локального сервера из исходников — `http://127.0.0.1:8080`. Windows использует `/ws` на том же HTTPS-домене. Пароль и токен не записываются на диск.

Проверка загрузки: SHA256SUMS.txt рядом с архивами содержит хэши архивов; внутри каждого архива — хэши его файлов. Windows: `Get-FileHash .\имя.zip -Algorithm SHA256`; Linux: `sha256sum -c SHA256SUMS.txt`. Хэши обнаруживают повреждение, но не заменяют цифровую подпись.

## Начало игры

Создайте аккаунт (пароль минимум 12 символов), затем героя: Страж, Арканист, Следопыт или Хранитель. Во вкладке «Вещи» наденьте кольцо. «Поход» → область → «Подготовить / присоединиться» → «Начать». Друзья вводят код группы **до** начала; группа до четырёх игроков.

Щёлкните карту или нажмите Esc для управления. WASD/стрелки — шаг; Space — атака; 1 — щитовой удар, 2 — защита, 3 — зелье; 4–0, Q, Z, C, V, G — заклинания. Цель — щелчок по врагу или Tab; правый щелчок сразу атакует. Огненная волна [C] и скачок [Z] летят по направлению последнего шага. Перезарядки видны на панели под картой. F — открыть сундук, испить из родника, коснуться алтаря. У золотого выхода E ведёт на следующий этаж, X возвращает с добычей. R помогает соседнему павшему союзнику. T открывает городские службы вне похода. F1 — подробный справочник.

Подземелье бесконечно: босс ждёт каждые 3–5 этажей, после него можно спускаться дальше или вернуться с добычей. Враги сильнее с глубиной и со средним уровнем группы. Первый босс области открывает следующую (всего шесть). Рекорд глубины попадает в таблицу лидеров.

Дуэль: во вкладке «Поход» выберите режим «Дуэль», передайте код сопернику, лидер начинает. Победа меняет только рейтинг.

Враги разных областей отравляют, замедляют, выпивают ману, лечат друг друга и взрываются при смерти. Матёрые враги (золотая рамка) дают двойную награду, эссенцию и вещь. Боссы (корона) призывают подмогу и бьют по площади — не стойте вплотную, когда рядом нет защиты.

В городе доступны кузница (32 рецепта, часть требует эссенцию), перегонка эссенции, разбор, доска контрактов, рынок, друзья, гильдии, таланты и история операций. Контракт засчитывает убитых врагов нужного вида только после эвакуации. Добыча сохраняется при эвакуации; при поражении остаётся четверть опыта. Постоянная экипировка не пропадает.

Если герой не двигается: убедитесь, что лобби запущено, закройте поле ввода клавишей Esc, дождитесь готовности действия. При разрыве соединения клиент пытается переподключиться; после нового входа выберите прежнего героя. При несовместимости версии запросите у владельца сервера актуальный клиент.
