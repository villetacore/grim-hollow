# Проверка подготовки поставки 0.3.0

Проверено локально 30 сентября 2026:

- Упаковщик: проверки исключения секретов/данных, совпадения тега с VERSION и контрольных сумм — успешно.
- GitHub workflows: actionlint — без ошибок. Удалённый GitHub Actions run ещё не выполнялся, репозиторий и доступ к GHCR задаёт владелец.
- Исходный ZIP распакован в отдельную папку. Windows-клиент собран из неё через Lazarus 4.8/FPC 3.2.2; Linux-клиент — через Docker Debian bookworm.
- Production PHP-FPM image собран из чистого экспортированного проекта. `php-fpm -t` успешен, `/game/VERSION` содержит 0.3.0.
- Production Compose прошёл `config --quiet` с шаблоном настроек. Он не разворачивался на публичном адресе; сертификат и сетевой доступ должны проверяться владельцем после размещения.
- Linux GUI smoke прошёл на реальном локальном сервере: город, экипировка, чат, старт, клавиатурное движение. Windows GUI был проверен на той же игровой реализации до упаковки.
- PHP: 35 тестов, 10 223 assertions успешно. Ранее та же игровая реализация прошла полный набор на отдельной MySQL.
- Импорт исходников проверен во временном Git-репозитории: `git add .` и проверка tracked-файлов прошли; сгенерированный SHA256SUMS.txt не попадает в commit.

Результат: архивы клиента Windows/Linux, исходников и серверных конфигураций плюс SHA256SUMS.txt в dist/releases. Ни готового GHCR image в удалённом registry, ни опубликованного GitHub Release локальная проверка не создаёт. Их публикует workflow после загрузки проекта и push совпадающего тега.

Windows CI использует Lazarus 4.4, установленный setup-lazarus; этот конкретный hosted runner сможет быть проверен только первым удалённым прогоном. Локальная проверка на 4.8 не подменяет его результат. Linux-клиент пока не поддерживает удалённый TLS/WSS, это явно указано в руководстве и архиве.
