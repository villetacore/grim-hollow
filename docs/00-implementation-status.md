# Реальное состояние реализации

**0.3.0 / campaign-003 «Три огня», 29 сентября 2026.** Первая локальная игровая поставка для 1–4 игроков. Инструкция и границы версии: [как играть](15-first-version.md). Документы 01–12 описывают более широкий целевой MMO-проект; все этапы S0–S4 не завершены.

30 сентября оформлены CI/CD и архивы распространения: [инструкция публикации](16-distribution.md), [проверка поставки](18-release-validation.md). Удалённый CI ещё не запускался.

## Реализовано

- PHP 8.4 / Laravel 13, MySQL 8.4, Workerman, Docker; Object Pascal / Lazarus / LCL Canvas.
- Аккаунты, отзываемые 8-часовые сессии с ротацией, до восьми героев, четыре класса, лобби с кодом на четыре места.
- Три последовательно открываемые области, по три процедурных этажа 32×32, четыре базовых поведения врагов и финальный босс. Возвращение третьего огня завершает кампанию.
- Бой, магия, мана, предметы, 20 уровней, характеристики, классовые таланты, дальняя атака следопыта и лечение союзников хранителем.
- Поднятие павшего: окно 20 секунд, действие 3 секунды, прерывание уроном; один заряд воскрешения на переходах за поход.
- Рюкзак, 11 определений вещей, четыре слота, привязка при надевании, торговец, разбор, четыре рецепта кузницы, дополнительные зелья.
- Торговая доска: предмет удерживается в escrow до покупки/отмены, комиссия 5%, транзакции и уникальные операции предотвращают повторные списания/выдачи.
- Гильдии, приглашения, смена главы при выходе, друзья между аккаунтами с подтверждением, общий/групповой/гильдейский чат.
- Жалобы и экран модерации, временное ограничение чата, журнал решений; роль администратора выдаётся только консолью.
- Журнал экономических проводок. Снимки мира, начальный снимок и журнал событий с проверкой воспроизведения для новых походов этой версии.
- Windows HTTPS через WinHTTP с системной проверкой сертификатов, WebSocket-снимки, переподключение, ротация сессии. Linux пока использует локальный HTTP polling.
- Новый пиксельный рендерер, миникарта, городская сцена, городские вкладки, справочник F1, крупное окно с прокруткой панелей и очередью клавиатурного действия.
- Скрипт резервной копии с импортом в отдельную БД, production Dockerfile PHP-FPM, конфигурации Nginx/Caddy, конфигурация CI.

## Измерение игровых расчётов

60,07 секунды; 100 персонажей в 25 зонах; 598 тактов и 59 800 представлений видимости. Время одного общего кадра: p50 25,880 мс, p95 58,587 мс, p99 79,152 мс. Пиковая память PHP 24 МБ. Команда: `php artisan game:benchmark --seconds=60 --players=100`.

Это **только правила и сериализация видимости**, без MySQL, HTTP/WebSocket и сетевых клиентов. Это не подтверждение 100 CCU. Сетевой часовой soak не проведён.

## Что остаётся за границей первой поставки

- Linux TLS/WSS, подписанный установщик/автообновление и проверка на чистых пользовательских ОС.
- Публичный сервер и домен, полная проверка Caddy/Nginx/FPM и административной эксплуатации.
- 100 реальных сетевых клиентов, длительная нагрузка, конкурирующие покупки и более широкий набор аварийных испытаний.
- Распределённое владение зонами, epoch/leases, Redis/outbox, миграция старых игровых снимков между версиями контента.
- Общая передвижная городская зона, полный контент исходного проекта, отдельные механики каждого биома, баланс кампании, звук и дополнительная доступность.
- Email verification, восстановление пароля и расширенная поддержка аккаунтов.

Город этой версии — иллюстрированная сцена и работающие службы. Биомы используют общие генератор и AI с различающимися параметрами. CI-файл подготовлен, удалённый запуск CI не заявляется. Проверка резервной копии не заменяет полный production restore drill с переключением серверов.
