# Changelog

## 0.3.1 — Быстрый отклик

Ускорение сетевой игры через удалённый HTTPS-сервер.

- Windows-клиент: одна WinHTTP-сессия с переиспользованием соединений вместо нового TCP/TLS-рукопожатия на каждый запрос.
- Команды в бою отправляются по уже открытому WSS; HTTPS остаётся резервным путём. Лишний HTTP-опрос после каждой команды убран, снимки мира из WSS применяются сразу, а не по таймеру.
- Сервер world после команды сразу отправляет игроку новый снимок, не дожидаясь следующего такта.
- Production Compose: `MYSQL_FLUSH_LOG_AT_TRX_COMMIT` и `MYSQL_SYNC_BINLOG` для медленных дисков (по умолчанию прежняя максимальная надёжность).
- Серверные образы возвращены на PHP 8.4: автообновление до 8.5 ломало сборку расширений. Переход на 8.5 будет отдельным изменением.

Сохранения, протокол HTTP API и формат игры совместимы с 0.3.0.

## 0.3.0 — Три огня

Первая локальная кооперативная поставка для 1–4 игроков.

- Четыре класса, три области кампании, девять процедурных этажей, финальное возвращение третьего огня.
- Инвентарь, снаряжение, магия, 20 уровней, таланты и спасение союзников.
- Городские службы: ремесло, разбор, запасы, рынок, гильдии, друзья, хроника.
- Чат и модерация; транзакционные операции, сохранение походов и проверка replay.
- Pascal-клиент с пиксельной сценой, миникартой, ретро-панелями и справочником F1.
- Windows HTTPS/WebSocket, ротация сессий и переподключение.
- Поставка: архивы Windows/Linux, исходники, конфигурация сервера, GHCR image и SHA-256; CI проверяет сервер и собирает клиенты.

Ограничения: Linux-клиент пока только для локального HTTP, нет подписанного установщика/автообновления, полного сетевого теста 100 CCU и публичной эксплуатационной приёмки. Подробности — docs/00-implementation-status.md.
