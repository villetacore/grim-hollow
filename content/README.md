# Игровой контент

Будущие определения классов, умений, предметов, врагов, биомов, комнат, добычи, заданий и рецептов; локализация ru/en; исходники тайлов, спрайтов, звука и UI. Сейчас игровых ресурсов нет.

Контент имеет стабильные ID и отдельную версию поставки. Опубликованный пакет неизменяем. Публичный пакет не содержит скрытые таблицы и серверные seed. Валидация и публикация описаны в [структуре проекта](../docs/06-repository.md).
