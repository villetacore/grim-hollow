# Сообщения об уязвимостях

Для закрытого сообщения используйте вкладку Security → Report a vulnerability в GitHub-репозитории, если владелец включил Private vulnerability reporting. Если кнопки нет, сначала запросите у владельца приватный канал без публикации деталей эксплуатации и чужих данных.

Владельцу: включите Private vulnerability reporting, Dependabot alerts и защиту основной ветки перед публичной публикацией. Контакт владельца здесь намеренно не выдуман.

В отчёте укажите версию/commit, затронутый компонент и воспроизводимые шаги на собственном тестовом сервере. Не прикладывайте реальные пароли, сессии, дампы аккаунтов и ключи.

0.3.x — первая локальная поставка; публичная эксплуатация ещё не проходила полную приёмку. Нет гарантированного срока исправления. Публичный сервер должен использовать HTTPS/WSS и свои случайные секреты. Только edge публикует порты; MySQL/API/world остаются во внутренней сети production Compose.
