# Инструменты

- `setup.ps1` / `setup.sh`: сервер и MySQL в Docker.
- `build-client.ps1`: Windows-сборка Lazarus.
- `play.ps1`: открыть готовый клиент.
- `test-mysql.ps1`: PHPUnit в отдельной MySQL-базе.
- `test-client.ps1`: скрытый smoke-тест Windows GUI на локальном сервере.

Редактор контента и просмотрщик повторов ещё не реализованы. Сетевые боты находятся в `tests/e2e`.
