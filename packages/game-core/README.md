# Игровое ядро PHP

`Game` исполняет команды и такты, `Dungeon` создаёт связные карты, `Random` сохраняет состояние PRNG, `Canonical` нормализует JSON для устойчивого хэша. Нет зависимости от Laravel, БД, сети или системного времени.

Тесты находятся в `apps/server/tests/Unit/GameTest.php`. В прототипе параметры контента находятся в коде; внешние таблицы пока не реализованы.
