# Клиент Pascal / Lazarus

Проект: `GrimHollow.lpi`. Windows-сборка из корня: `tools/build-client.ps1`; результат — `dist/windows/GrimHollow.exe`. Linux-сборка проверяется Dockerfile клиента.

Версия 0.3.1 использует LCL Canvas и HTTP в отдельном потоке. Windows-адаптер WinHTTP поддерживает HTTPS, WebSocket/WSS, системную проверку сертификатов и переподключение. HTTPS-запросы идут через одну WinHTTP-сессию с переиспользованием соединений; в бою команды отправляются по уже открытому WSS (HTTPS остаётся резервным путём), а присланные сервером снимки применяются сразу. Linux-адаптер пока допускает только локальный HTTP:8080. Пароль и токен обычного клиента не сохраняются на диск. SDL2 не используется.

`GameArt` рисует пиксельные тайлы и город; `GameRenderer` — поле и миникарту; `TownWindow` — городские службы; `FieldGuide` — справочник F1. [Содержание первой версии](../../docs/15-first-version.md).

`--smoke` — сетевой GUI-тест в Docker, `--smoke-local` — на Windows. Каждый создаёт свой аккаунт, героя и забег, сохраняет снимок собственного окна.
