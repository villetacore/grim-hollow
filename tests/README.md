# Проверки

`e2e/smoke.mjs`: два участника, WebSocket, течение времени и повторы команд. `e2e/gameplay.mjs`: исследование видимой карты, бой, эвакуация и сохранение. Нужны Node.js 22+ и dev-сервер; создаются отдельные тестовые аккаунты.

PHPUnit находится в `apps/server/tests`; обязательный интеграционный прогон использует отдельный MySQL. GUI smoke встроен в клиент. Нагрузочный и длительный аварийный тесты ещё не реализованы.
