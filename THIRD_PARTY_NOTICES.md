# Third-party notices

Original project files use the terms in LICENSE. Dependencies keep their respective licenses.

## Client

- Free Pascal 3.2.2 runtime and standard units: modified LGPL with linking exception; notices in `LICENSES/FPC-COPYING.txt` and `LICENSES/FPC-COPYING.FPC`. Sources: https://gitlab.com/freepascal.org/fpc/source/-/tree/release_3_2_2
- Lazarus LCL: modified LGPL with linking exception; `LICENSES/Lazarus-COPYING.LGPL.txt` and `LICENSES/Lazarus-COPYING.modifiedLGPL.txt`. Sources: https://gitlab.com/freepascal.org/lazarus/lazarus. Windows CI uses Lazarus 4.4 / FPC 3.2.2; Linux image uses Debian bookworm Lazarus 2.2.6 / FPC 3.2.2. These libraries are not modified by this project.
- Linux client dynamically uses the system GTK2 stack, distributed by the operating system; it is not bundled in the client archive.
- Windows client calls the operating system's WinHTTP API; no Windows libraries are redistributed in the archive.

The Lazarus IDE/compiler executable is not included in the client package. Pixel art in GameArt.pas is generated by the original project code; no World of Warcraft or Dungeon Crawl assets are distributed.

## Server

Laravel-derived application scaffolding keeps the upstream MIT notice in `LICENSES/Laravel-MIT.txt`; the project's original-code notice does not override it.

Laravel, Workerman and other PHP dependency versions, sources and license identifiers are recorded in `apps/server/composer.lock`. Composer installs their upstream LICENSE files under `vendor/` inside the server image. They must remain in redistributed images. To inspect: `composer licenses --format=json` in `apps/server` after installation.

PHP/Debian base images, MySQL, Nginx and Caddy are separate upstream container distributions with their own licensing notices. Server source archives do not bundle their binaries. Source and dependency links: https://www.php.net/ · https://www.debian.org/ · https://github.com/laravel/framework · https://github.com/walkor/workerman · https://www.mysql.com/ · https://nginx.org/ · https://github.com/caddyserver/caddy
