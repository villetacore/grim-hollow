# Контракты

Действующий контракт локального прототипа — [prototype-v1.md](prototype-v1.md). Полные `http/openapi.yaml`, JSON Schema realtime v1, схемы контента и общий набор fixtures ещё предстоит реализовать. Целевой проект: [протокол](../docs/08-protocol.md), [данные](../docs/07-data-model.md) и [пример контента](../docs/06-repository.md).

Любое несовместимое изменение требует новой версии. Fixture обязан проходить одинаково на PHP и Pascal. Схемы создаются до соответствующих обработчиков на этапе S0.
